# 知了猴整蛊台

面向 Windows 主播的直播互动桌面客户端，使用 Electron、React 和 TypeScript 构建。它把直播事件、礼物规则、游戏桥接和直播画面挂件放在同一个桌面应用中。

## 功能

- 游戏库、Mod 安装与更新、游戏启动和参数配置。
- 直播间连接（抖音、哔哩哔哩）、礼物与弹幕事件、直播统计和礼物记录。
- 时间插件、礼物加减时间、时间盲盒、计时与计数挑战。
- 特色整蛊：锁链、抓鸭子、粉丝来电、音乐球等 17 个叠在直播画面上的互动玩法，可由礼物、转盘、九宫格、时间盲盒和整蛊遥控触发，支持盲盒、随机数量和横竖屏画面。
- 八套萌宠时间皮肤：奶油小狗、薄荷双狗、桃桃小猫、晚安猫咪、草莓兔兔、面包仓鼠、水豚温泉、星际小猫。
- 礼物菜单支持一到三列，随礼物数量和图标大小调整；配件带轻微摆动，可关闭。
- 转盘和九宫格抽奖、积分心愿、排队、飘屏、进场横幅、贴纸统计、键盘显示和视频播放。
- 绿幕与透明输出窗口，可作为直播软件的窗口采集来源。

## 开发环境

- Windows 10 / 11，64 位。
- 推荐使用 **Node.js 24 LTS**，本项目提供 `.nvmrc`。本次完整安装与构建使用 Node.js 24.19.0、npm 11.19.0 验证。
- Python 3.11：运行 Python 连接器时需要。

```sh
npm ci
npm run dev
```

本机测试中，Node.js 26.7.0 运行 Electron 33 的安装脚本会提前退出，留下不完整的运行时；请使用上面的 Node 24 LTS。npm 11.19 的依赖安装脚本按项目许可运行，`package.json` 仅允许锁定版本的 Electron 和 esbuild 安装脚本。升级这两个依赖时，需要重新审核并更新对应条目。

检查和构建：

```sh
npm run typecheck
npm run build
```

`build` 编译到 `out/`，不会发布或自动替换已安装的客户端。启动开发版会使用应用的本地配置；运行验收脚本时则使用单独的测试配置和临时游戏路径。

## 可选运行资源

源码快照保留应用、连接器、资源清单和通用工具，以下体积较大或具有独立来源的资源需要按用途准备：

| 资源 | 说明 |
| --- | --- |
| 平台礼物图 | `gift-assets/douyin/catalog.json` 是资源清单。可通过应用的礼物同步能力或 `npm run gifts:sync` 获取；图片权利归各自权利人。 |
| 游戏 Mod 安装包 | 由各 Mod 清单指定的下载地址获取，源码仓库不存放游戏 DLL 或安装包。 |
| 嵌入式 Python | 正式版放在 `pyembed/`；开发者可自行准备 Python 3.11 运行时及连接器依赖。 |
| FFmpeg | 视频处理功能使用 `ffmpeg/` 中的独立运行时，请保留下载分发包自带的许可证。 |
| 游戏封面与截图 | 不随首个源码快照再分发，应用保留资源路径与在线来源。 |
| 特色整蛊素材 | 玩法使用的图片、音效和视频放在 `assets/special-games/`，不随源码快照分发，权利归各自权利人。需要完整画面时自行准备该目录；`verify-special-games`、`verify-special-portrait` 等验收脚本也依赖它。 |

运行真实直播连接器还需要你自己账号的登录态。不要把 cookie、令牌、账号数据库或运行日志提交到仓库。

## 项目结构

```text
src/main/                 Electron 主进程、IPC、连接器与输出窗口
src/preload/              主进程与界面之间的 API
src/renderer/             React 界面与公开的应用资源
src/shared/               共享类型、格式化和皮肤规则
connector-assets/         Python 直播连接器及签名模块
mods-catalog/             游戏与 Mod 的公开清单、参数 schema
assets/emoji72/            Twemoji 图形及许可
tools/                    开发、资源同步与验收工具
build/                    图标、公共配置和打包钩子
```

## 皮肤与输出窗口验收

准备好礼物图等测试资源后：

```sh
npm run test:entertainment:nobuild -- --hidden
node tools/verify-pet-countdown.mjs
node tools/verify-pet-native.mjs
```

第一个命令验证通用娱乐功能。第二个命令验证八套皮肤、菜单伸缩、真实走秒和礼物加时。第三个命令只创建自己的测试窗口，验证 Windows PrintWindow / BitBlt 采集及动态帧；不会连接直播间或启动用户游戏。报告保存在 `output/playwright/`。

## 配置与部署

`build/license-provider.json` 仅包含服务地址和公开验签信息，私钥位于服务端。本仓库不包含配套管理后台或授权服务。自行部署时，应配置自己的服务地址、公开验签信息与更新源，并使用自己的应用标识。

正式安装包使用的完整打包配置为 `electron-builder.yml`。开源源码快照会提供只包含已公开资源的打包配置；缺少的独立运行时需要开发者自行补齐后再分发。
